# Données — ArenaKick

## Description
Jeu de données synthétique représentant des tournois
de football typiques dans le contexte malgache.

## Contenu
- `tournois.json` — Tournois de démonstration
- `equipes.json` — Équipes participantes
- `joueurs.json` — Joueurs par équipe
- `matchs.json` — Matchs générés par Round-Robin
- `classements.json` — Classements calculés

## Génération
```bash
python generate_data.py
```

## Source
Données synthétiques générées pour démonstration.
Noms d'équipes inspirés de clubs malgaches réels.
